🔄 Đồng Bộ Nhiều Thiết Bị

Dữ liệu mặc định chỉ lưu trên máy này (localStorage). Để nhiều iPhone cùng xem/sửa chung 1 lịch, cần kết nối tới 1 Firebase Realtime Database miễn phí (chỉ cần làm 1 lần).

  1. Vào console.firebase.google.com → Đăng nhập Google → Add project (đặt tên tuỳ ý, ví dụ cuxa-lichtruc) → tắt Google Analytics cho nhanh.
  2. Trong project vừa tạo, vào mục Build → Realtime Database → Create Database → chọn vị trí bất kỳ → chọn chế độ Start in test mode.
  3. Vào tab Rules của Realtime Database, dán đè: 
    { "rules": { ".read": true, ".write": true } }
    rồi bấm Publish. (Lưu ý: cách này đơn giản, ai có link project cũng đọc/ghi được - phù hợp cho lịch trực nội bộ, không phải dữ liệu nhạy cảm.)
  4. Bấm ⚙️ (Project settings) ở góc trên trái → cuộn xuống Your apps → bấm icon </> (Web) → đặt tên app → Register app.
  5. Firebase sẽ hiện đoạn code chứa const firebaseConfig = {...}. Copy toàn bộ đoạn đó và dán vào ô bên dưới.

Mẹo: sau khi làm xong trên 1 máy, gửi đoạn cấu hình này cho các máy khác (qua Zalo) để dán vào - hoặc nhờ mình "nướng" thẳng vào file để mọi người mở lên là tự động đồng bộ, không cần dán gì cả.
